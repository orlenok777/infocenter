# Инфоцентр помощников

Публичный снимок инфоцентра для телефона.

Живые индикаторы, микрофон, поток событий и захват звука приложений работают только в локальной версии на Mac. Здесь показывается застывшее состояние страницы: помощники, задачи, квоты, сводки, решения и история версий.

Страница обновляется вручную пересборкой `data.json`.

## Как включить GitHub Pages

Репозиторий уже создан, файлы лежат в ветке `main`. Сам сайт ещё не опубликован: у коннектора GitHub нет права включить Pages.

Откройте [настройки Pages](https://github.com/orlenok777/infocenter/settings/pages) и в разделе **Build and deployment** выберите источник **GitHub Actions**. После этого запустите workflow `pages` вручную (Actions → pages → Run workflow) или сделайте пустой коммит. Адрес страницы: https://orlenok777.github.io/infocenter/
