# Инфоцентр помощников

Публичный снимок инфоцентра для телефона.

Живые индикаторы, микрофон, поток событий и захват звука приложений работают только в локальной версии на Mac. Здесь показывается застывшее состояние страницы: помощники, задачи, квоты, сводки, решения и история версий.

Страница обновляется вручную пересборкой `data.json`.
